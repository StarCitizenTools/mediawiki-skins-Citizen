3.24.0

Oct 1, 2026

🧩 Cache status: covered by compat — set $wgCitizenCompat = true; to upgrade without a purge.

Highlights

  • 🧩 Add your own panels to the side column Wikis can now give the side column panels of their own, such as a recent changes feed, filled by a gadget or site script. Pages with only Last modified no longer show the side column by default. See Side column.

  • 🔎 Go straight to the page you typed Pressing Enter in the command palette now opens the page you typed, rather than a search for it. Recent also lists each page once however you opened it, holds up to eight entries, and leaves out the page you are on, and ? opens help as a list of modes you can search.

  • 🎨 Easier-to-read code Syntax colors in code blocks have been rebalanced so every one stays readable against the block in both light and dark mode, and the CodeMirror and CodeEditor editors keep the skin's colors, including on MediaWiki 1.46.

  • 📑 A redesigned collapse toggle in the table of contents The toggle now sits on the outline's rail, so long headings keep their full width and the toggle stays level with their first line.
