3.21.0

Aug 16, 2026

⚠️ Using UploadWizard? The sidebar's "Upload file" link is now the one MediaWiki builds, so Citizen no longer points it at UploadWizard by itself. See Point the upload link somewhere else to send people there again.

✅ Cache status: clean — no purge required after upgrading.

Highlights

  • 📤 The upload link follows your wiki's settings "Upload file" now honours $wgUploadNavigationUrl and only shows up for people who are allowed to upload, and Special:Upload itself is styled to match the rest of the skin.

  • 🔍 Command palette results you can read Badges no longer squeeze out the page title, redirect labels that just repeat the title are hidden, and pressing Enter opens the result you typed for rather than one that arrived a moment later.

  • 📱 A richer app install prompt Wikis can now give the installable app its own shortcuts and screenshots, so the install dialog can show what the wiki looks like and the installed app can jump straight to the pages people use most — see Progressive Web App.
