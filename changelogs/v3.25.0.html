3.25.0

Oct 27, 2026

🧩 Cache status: clean — no purge needed.

Highlights

  • 🕘 Recent shows where you went, not what you clicked Recent in the command palette now remembers the place a row took you to, so a page looks like that page whether you reached it from search, related articles or a Go.

  • 🐛 Bug fixes Fixes across the media viewer, editors, command palette and page tools, including images no longer cut off at the bottom in the media viewer, an editing font that follows your font size preference, edit counts and dates shown in your interface language, and more.
