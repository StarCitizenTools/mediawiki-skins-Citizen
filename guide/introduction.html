Introduction ​

Citizen is a beautiful, usable, responsive MediaWiki skin that makes extensions part of the cohesive experience. Originally made for the Star Citizen Wiki, it has now been made flexible to run on various MediaWiki configurations.

Unlike the other standard MediaWiki skins, Citizen has a lot more to offer:

Responsive layout
The skin is responsive and is able to adapt to different screen sizes.
Command palette
Citizen's search is an upgrade, with a better search experience and support for custom commands.
Theme modes
Users are able to personalise the wiki by choosing between light, dark, or even darker mode.
Cohesive extension styles
With tons of the skin's supported extensions, it has been made to blend with the skin's UI.
Extensible preferences
Let users personalize their experience, and let gadgets add their own options.
Collapsible sections
Article sections on the wiki can be collapsed and expanded.
Progressive web app
Users can add a wiki using Citizen to their home screen, giving a more app-like experience.

Citizen is a small open-source project, and we really appreciate any help from the community. Feel free to contribute towards the project ❤️
